# dsh-message-recall

DeepSeek Harness 的消息撤回插件。

**每条用户消息、每条助手回复都有自己的撤回按钮**，功能完全一致。被撤回的内容会真正从对话和模型上下文里移除——不是藏起来，下一轮对话模型就不再知道它。

## 使用

消息气泡下方、复制按钮旁边有一个撤回箭头。点击后选择范围：

| 选项 | 作用 |
| --- | --- |
| 仅撤回这一条 | 只移除这一条消息 |
| 撤回这条及之后 | 从这条开始，一直到对话末尾 |

两种模式都只向**时间线后方**作用，比当前更早的消息不会受影响。

撤回后界面立即更新，不会刷新页面、不会丢失滚动位置。

## 注意事项

- 撤回后无法撤销，请确认范围再操作。
- 只能在当前打开的会话里撤回。
- Web 界面与桌面客户端使用同一份实现，功能相同。

## 安装

```bash
# 在 DSH profile 目录（$DSH_HOME/profiles/<profile>）里
pnpm add link:/path/to/dsh-message-recall
```

然后在同一个 `package.json` 的 `dsh.profile.bundles` 里加入 `"dsh-message-recall"`，重启 DSH。
